# Airline Passenger Satisfaction — STAT 112 Final Project

**STAT 112 final group project · Middle East Technical University · Fall 2024–25**

We used Python to clean and explore a course dataset of 1,000 airline passenger records and 17 variables. The analysis covers passenger satisfaction, travel purpose, flight distance, ticket prices, delays, and service ratings.

[Explore the notebook](Stat112_Final_Group_Project.ipynb) · [Read the report summary](REPORT_SUMMARY.md) · [View the dataset](airline_passenger_satisfaction.csv)

## My contribution

I built the **Travel Type and Gender by Flight Distance** visualization. I used a Seaborn boxen plot to compare flight-distance distributions across gender and business or personal travel, with consistent colors and a shared scale. My section is marked **Visualization by Aslı Ceren Aksu** in the notebook.

## Run the notebook

1. Download the repository and keep the CSV beside the notebook.
2. Install the dependencies with `python -m pip install -r requirements.txt`.
3. Open the notebook in Jupyter, set its working directory to the repository, and run the cells in order. The CSV uses a semicolon delimiter.
