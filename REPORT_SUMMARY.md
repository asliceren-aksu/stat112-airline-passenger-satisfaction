# Project report summary

The team explored relationships among passenger characteristics, trip details, service ratings, and satisfaction. We checked the raw dataset for duplicates, standardized column names and category labels, converted numeric fields, and inspected missing values and unusually large or small observations. The notebook documents the original decisions, including replacing extreme values beyond a 3-IQR rule and using mean or mode imputation where applicable.

We reviewed descriptive statistics before creating seven visualizations. The original report describes age and flight distance as roughly symmetric in this sample, while the departure and arrival delay distributions were somewhat right-skewed. The individual visualization sections show which team member developed each chart.
